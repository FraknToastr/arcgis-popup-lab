ARCGIS POPUP LIVE BRIDGE — PROTOTYPE 1.1

Popup-to-app-to-popup live bridge

Supports direct FeatureServer edits and bridge-table persistence for read-only or multipatch layers.

Layer A source popupEdit a real attribute or store a feature-specific bridge value, then publish it to the scroller channel. External sine scrollerPoll the live channel and send a value to either an editable Layer B feature or a read-only Layer B bridge state. Layer B target popupWatch a FeatureServer field or the shared bridge state and update the open popup live.

Multipatch path

Multipatch popup iframe
    │ selected feature bridge_key
    │ update/add feature-state row
    ▼
Editable ArcGIS hosted bridge table
    │ query every 0.5–2 seconds
    ├──────────────► External sine scroller
    │
    └──────────────► Another open multipatch popup

Before use

  1. Run Popup_Live_Bridge_Schema_Tool.pyt on Layer A, Layer B, and the bridge table.
  2. Publish the bridge table as an editable hosted table with Query, Create, and Update.
  3. Edit config.js and publish this directory through GitHub Pages.
  4. Configure each Arcade expression as direct or bridge.
  5. Register urn:ietf:wg:oauth:2.0:oob on the OAuth application.
